GitHub-adgang

For at gemme skal du bruge en fine-grained GitHub-token med adgang til testkonto26/testside og tilladelsen Contents: Read and write. Token bruges kun til at gemme direkte på GitHub.

Din token bliver ikke gemt i hjemmesidens filer eller browserens lager. Alle besøgende kan se streamtallene, men kun personer med GitHub-skriveadgang kan ændre dem.
